# 一胎18个

一款以「纸制手账」风格打造的**体重管理与饮食热量记录**安卓应用。用翡翠绿主色 + 暖白纸感背景，把每日热量、宏量营养素与身体数据收进一本轻量、清爽的移动手账里。

## 🏔 稀缺性：它和市面上的热量 / 体重 App 有什么不一样

市面上的记录类应用大多要么需要注册账号、数据上云，要么对「天然食材」覆盖不足，要么体重趋势只是把点连成一条线。这个项目选择反着来：

1. **真・本地优先，无账号、无云端**：体重、腰围、三餐与摄入数据全部存在设备本地的 Room 数据库与 DataStore 里，离线可用，不上传任何个人数据，用完即走、隐私自留。
2. **根治「食材录不进」的痛点**：内置 **150+ 预置食材**，专门覆盖菜市场里**没有营养成分表**的天然食物——鲜菜、鲜肉、水产、豆制品、干货、蛋类，这些在其他 App 里要么缺失要么要付费解锁。
3. **体重趋势是「算」出来的，不是「画」出来的**：用**时段加权 Theil-Sen 稳健回归**代替简单折线——对水分波动、偶发夜秤等离群点天然免疫，并让最可靠的「晨起空腹」样本获得更高置信权重。
4. **历史记录不被食物库更新破坏**：每条餐次固化「食物名称 + 热量」快照，之后加菜改名都改不动过去的数据；自定义食物与预置同名自动合并，不产生重复、不错算热量。
5. **手账纸感 UI、翡翠绿主色调**：拒绝千篇一律的卡片堆叠，以信息层级优先与大量留白为原则，核心数字用大号衬线字体呈现。

## ✨ 功能特性

- **首页热量看板**：今日剩余热量大号衬线数字呈现，搭配刻度尺直观展示摄入进度，一眼掌握今日能量结余。
- **三餐饮食记录**：早餐 / 午餐 / 晚餐 / 加餐分类记录，食物分量按克输入，自动换算热量与蛋白质、碳水、脂肪、钠四项宏量营养素。
- **内置食物库**：内置 **150+ 预置食材**，覆盖主食、蔬菜、肉类、禽蛋水产、豆制品、干货、坚果、食用油酱料、水果与零食等全类目，并支持自定义食物。数据取自《中国食物成分表》。
- **体重 / 腰围管理**：每日记录体重与腰围，测量时段可选（晨起空腹 / 餐后 / 练后 / 其他时段），并依据录入时间自动推断常见的「晨起空腹」时段。
- **科学体重趋势**：采用**时段加权 Theil-Sen 稳健回归**估算体重变化趋势——既抗离群点（水分波动、偶发夜秤），又对最可靠的「晨起空腹」样本给予更高置信权重。
- **日志回看**：周条日历快速切换日期，餐次明细与当日/当餐热量一目了然。
- **身体状态**：我的页集中展示体重趋势、身体指标与个人资料，支持头像设置（自动复制到应用私有目录持久化）。
- **个性化开机页**：粉圆环 + 跳动爱心动画的开机页，引导流程与主界面自动衔接。

## 🧭 核心设计

### 热量记录怎么做

每条餐次记录在录入时就把**食物名称 + 热量**作为快照固化到数据库，因此食物库后续增删改不会影响历史记录的热量统计；内置预置食物按名称去重写入，与用户自定义的同名食物自动合并、互不干扰。

### 体重趋势为什么用加权 Theil-Sen

- 传统最小二乘回归对首尾异常点杠杆作用大，短窗口下容易带偏趋势。
- Theil-Sen 取所有点对斜率的中位数，天然抗离群，适合权重、腹水等水分波动。
- 用户并不总能早晨空腹称重，因此对「晨起空腹 > 其他 > 练后 > 餐后」按时段加权，让趋势更锚定最可靠的样本，同时不剔除任何数据。

## 🚀 构建与运行

环境要求：Android Studio 建议版本、JDK 17+、Android SDK (compileSdk 36)。

```bash
# 克隆并构建
git clone https://github.com/Lbj060410/heat-calc-app.git
cd heat-calc-app
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，可直接安装到 Android 设备或模拟器体验。
